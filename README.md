# 📚 Book Library App

A simple Book Library application built with vanilla JavaScript that allows users to add, display, and manage a collection of books. This project demonstrates object-oriented programming concepts, DOM manipulation, and dynamic UI updates.

---

## 🚀 Features

* ➕ Add new books (title, author, etc.)
* 📖 Display a list of books
* 🗑️ Remove books from the library
* 🔄 Dynamic UI updates without page reload
* 🧱 Object-based data structure for books

---

## 🧱 Tech Stack

* **HTML** – structure
* **CSS** – styling
* **JavaScript** – logic and interactivity

## 🎮 How It Works

1. Enter book details (e.g., title, author)
2. Click “Add Book” to store it in the library
3. The book appears instantly in the UI
4. Remove books when needed
